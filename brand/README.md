# Brand sources

`ca-india-logo/` holds the official CA India logo exactly as downloaded from
ICAI (https://www.icai.org/post/2167, archive `caindia-logo-download.rar`),
plus ICAI's logo manual. These are source files for designers; they are not
copied into the site build. The web copy lives at `assets/logo/ca-india-logo.png`.

ICAI rules that apply to the site: use the logo unaltered (no colour, font,
spacing or proportion changes; scale only), on a white background, with the
clear space and minimum size from the manual.
